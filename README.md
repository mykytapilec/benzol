# 🧩 Benzol

Hexagonal 2048 — fullstack learning project  
Monorepo structure using **pnpm**, **TypeScript**, and **NestJS / React / React Native**

## Structure

/web - React web app
/mobile - React Native app
/server - NestJS backend
/shared - Shared TS types and utils


## Commands
- `pnpm install` – install all dependencies
- `pnpm dev:all` – run backend and web together
